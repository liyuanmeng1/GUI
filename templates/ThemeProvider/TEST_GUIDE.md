# ThemeProvider 测试指南

此测试项目用于验证 ThemeProvider 组件的功能完整性。

## 快速开始

### 1. 安装依赖

```bash
cd /Users/liyuanmeng/.codex/skills/KS-AI-UI/templates/ThemeProvider
npm install
```

### 2. 启动测试页面

```bash
npm run dev
```

访问 `http://localhost:5173` 查看效果。
